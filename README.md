# 💍 Noor-E-Mehal — Wedding Planner Management System

A complete wedding planner management system built with PHP, MySQL, and Bootstrap. Includes user registration, event booking, service management, and a full admin panel.

---

## ✨ Features

### 👰 User Side
- **User Registration & Login** — Secure authentication with password hashing
- **Event Creation** — Create and manage wedding events (Engagement, Mehndi, Baraat, Walima)
- **Service Booking** — Browse and book wedding services (Decoration, Catering, Photography, Makeup, Music, Venue)
- **Product Packages** — View detailed packages and pricing
- **Inquiry Form** — Contact form with wedding details
- **Booking Success** — Confirmation with booking details
- **FAQs & About** — Information pages
- **Gallery** — Images and videos showcase

### 👨‍💼 Admin Panel
- **Dashboard** — Overview of bookings, events, users
- **User Management** — Add, edit, delete, view users
- **Event Management** — Approve/reject events, edit details
- **Service Management** — Add, edit, delete book services
- **Booking Management** — View and manage all bookings
- **Product Management** — Add, edit, delete wedding packages
- **Inquiry Management** — View and respond to inquiries

### 📦 Services Available
- Decoration — Premium floral and stage decoration
- Catering — Delicious food for all guests
- Photography — Professional photography and videography
- Makeup — Bridal makeup and beauty services
- Music — Live band and DJ services
- Venue — Luxury hall rental

---

## 🛠️ Tech Stack

- **Backend:** PHP 8.4 (Procedural PDO)
- **Database:** MySQL 8
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Server:** Apache (XAMPP/WAMP)
